Step-by-Step Instructions to Deploy to GitHub Pages:

  1. Create a free account at GitHub.com if you don't have one.
  2. Click the "+" icon at the top right and select New repository.
  3. Name your repository (e.g., sound-vault-r-escape), make it Public, and click Create repository.
  4. Click uploading an existing file, save this code into a file named index.html, and drag/upload it into GitHub.
  5. Commit the file by clicking Commit changes.
  6. Go to Settings > Pages (on the left menu).
  7. Under Build and deployment > Branch, select main (or master) and click Save.
  8. Wait 1–2 minutes. GitHub will provide a live public URL (e.g., https://yourusername.github.io/sound-vault-r-escape/).
  9. Copy that live link and attach it to any button or link on your Wix website!
